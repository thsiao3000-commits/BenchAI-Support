隱私權政策

生效日期：2026 年 4 月 2 日

我們不收集任何資料。一切都留在您的裝置上。

1. 我們不收集的資訊

BenchAI 不會收集、儲存或傳輸：

  • 個人資訊（姓名、電子郵件、電話號碼）
  • 使用分析或行為資料
  • 對話內容或提示詞
  • API 金鑰或憑證
  • 用於追蹤的裝置識別碼
  • 位置資料
  • 崩潰報告或診斷資料

2. 儲存在您裝置上的資料

以下資料僅儲存在您的裝置本地，絕不會傳輸至 BenchAI 或任何第三方：

  • API 金鑰：使用 iOS Keychain 進行硬體級安全加密。金鑰不會包含在裝置備份中。
  • 聊天記錄：使用 Apple 的 SwiftData 框架儲存於本地。
  • 比較結果：使用 Apple 的 SwiftData 框架儲存於本地。
  • App 偏好設定：使用 UserDefaults 儲存於本地（主題、語言設定）。

3. 第三方服務

當您使用 BenchAI 時，您的提示詞和訊息會直接從您的裝置發送至您已設定的 AI 供應商：

  • OpenAI 隱私權政策
  • Anthropic 隱私權政策
  • Google 隱私權政策
  • Groq 隱私權政策

BenchAI 不作為中介。沒有 BenchAI 伺服器。您的資料使用您自己的 API 金鑰直接傳送至您選擇的 AI 供應商。

4. 資料安全

  • API 金鑰透過 iOS Keychain 進行硬體級加密
  • 所有網路通訊使用 HTTPS 加密
  • 不在外部伺服器儲存任何資料
  • 未整合任何第三方分析或追蹤 SDK

5. 兒童隱私

BenchAI 不會故意收集 13 歲以下兒童的任何資料。由於本 App 完全不收集任何資料，因此無需特殊規範。

6. 您的權利

  • 隨時從「設定 → 智慧金鑰」刪除 API 金鑰
  • 從「歷史」分頁刪除對話記錄
  • 解除安裝 App 即移除所有資料
  • 您對儲存在裝置上的所有資料擁有完全控制權

7. 政策變更

我們可能會不時更新本隱私權政策。任何變更將反映在 App 和本文件中，並更新生效日期。
